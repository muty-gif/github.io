En desarrollo

system-ticket

Un sistema de tickets de soporte IT, parecido a los que utilizan las empresas para gestionar incidencias de sus usuarios.

Estoy desarrollando una aplicación web de Help Desk para gestionar incidencias de soporte técnico. Los usuarios pueden crear tickets y los técnicos pueden gestionarlos, asignarlos, cambiar su estado y resolverlos. La estoy desarrollando con Python y Flask, utilizando una base de datos y autenticación de usuarios, mientras aprendo buenas prácticas de desarrollo de software.

¿Qué estoy aprendiendo?

Estoy aprendiendo desarrollo web de forma práctica: backend con Python y Flask, bases de datos, autenticación, CRUD, relaciones entre datos, Git y organización profesional de proyectos.
